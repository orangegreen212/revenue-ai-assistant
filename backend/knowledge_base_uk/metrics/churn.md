# Визначення

Churn Rate вимірює темп, з яким клієнти чи повторюваний дохід втрачаються за період. **Logo churn** (клієнтський churn) рахує втрачені акаунти; **revenue churn** вимірює втрачений MRR/ARR через скасування (а іноді й даунгрейди, залежно від визначення). Обидва — ключові індикатори ризику для передплатного бізнесу.

# Чому це важливо

Churn напряму обмежує, наскільки великою може стати повторювана база доходу, незалежно від того, наскільки сильне залучення нових клієнтів. Бізнес, який швидко додає клієнтів, але так само швидко їх втрачає ("дірявий кошик"), матиме труднощі з накопичувальним зростанням. Churn також напряму впливає на LTV — нижчий churn означає довшу середню тривалість життя клієнта і вищий LTV.

# Формула

**Logo churn rate:**

```
Logo Churn Rate = Клієнти, втрачені за період / Клієнти на початок періоду
```

**Revenue churn rate:**

```
Revenue Churn Rate = MRR, втрачений за період / MRR на початок періоду
```

**Gross vs. net revenue churn:**

```
Gross Revenue Churn = (Churned MRR + Contraction MRR) / Beginning MRR
Net Revenue Churn   = (Churned MRR + Contraction MRR − Expansion MRR) / Beginning MRR
```

Приблизна середня тривалість життя клієнта з місячного churn:

```
Середня тривалість (місяців) ≈ 1 / Місячний logo churn rate
```

# Приклад

Компанія починає місяць із 500 клієнтами, 20 з яких скасовують підписку.

```
Logo Churn Rate = 20 / 500 = 4%
```

Якщо ці 20 клієнтів становили $3 000 з початкового MRR у $60 000:

```
Revenue Churn Rate = $3 000 / $60 000 = 5%
```

# Типові помилки

- Змішування logo churn і revenue churn в одному числі без позначення, який саме звітується — вони відповідають на різні питання і можуть суттєво розходитись.
- Використання кількості клієнтів на **кінець** періоду як знаменника замість кількості на **початок**.
- Анаулізація місячного churn простим множенням на 12, що завищує реальну річну цифру (правильна формула компаундування — `1 − (1 − місячний churn)^12`).
- Врахування даунгрейдів як повного churn або їх повне ігнорування замість окремого відстеження як contraction.
- Незрозуміння добровільного churn (клієнт сам вирішує скасувати) від вимушеного (невдалий платіж) — виправлення для кожного повністю різні (робота з продуктом/CS vs. логіка повторних спроб оплати).

# Пов'язані метрики

- **GRR / NRR** — метрики утримання, які є оберненим поглядом на churn на рівні когорти.
- **LTV** — churn rate напряму впливає на середню тривалість життя клієнта, а отже й на LTV.
- **Customer Segmentation** — churn варто аналізувати за когортою, тарифом і терміном перебування, оскільки ранній churn часто домінує в змішаних цифрах.
