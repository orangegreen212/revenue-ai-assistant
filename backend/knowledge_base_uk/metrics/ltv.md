# Визначення

Customer Lifetime Value (LTV, або CLV) оцінює загальний валовий прибуток, який бізнес очікує отримати від клієнта за весь час співпраці. У SaaS LTV зазвичай виводиться з ARPU, валової маржі й churn rate, а не відстежується для кожного клієнта окремо.

# Чому це важливо

LTV — противага CAC: разом вони визначають, чи є двигун зростання компанії економічно стійким. LTV також показує, скільки бізнес може дозволити собі інвестувати в залучення, утримання чи customer success, не руйнуючи юніт-економіку.

# Формула

**Стандартна SaaS-формула (на основі валового прибутку):**

```
LTV = ARPU × Валова маржа % / Customer Churn Rate
```

**Еквівалентна форма через тривалість життя:**

```
Середня тривалість життя клієнта (місяців) = 1 / Місячний churn rate
LTV = ARPU × Валова маржа % × Середня тривалість життя
```

Використання **виручки** замість валового прибутку дає "Revenue LTV", який завищує реальну цінність клієнта і не повинен використовуватись у співвідношенні LTV:CAC.

# Приклад

Клієнт платить $100/місяць (ARPU), валова маржа бізнесу 80%, місячний churn — 2%.

```
Середня тривалість = 1 / 0.02 = 50 місяців
LTV = $100 × 0.80 × 50 = $4 000
```

# Типові помилки

- Використання виручки замість валового прибутку в співвідношенні LTV:CAC, що завищує співвідношення й приховує потенційно нестійку економіку.
- Змішування місячного ARPU з річним churn rate (чи навпаки) без послідовної конвертації одиниць.
- Припущення про постійний churn, коли ранні когорти часто йдуть швидше за зрілі — когортний LTV точніший за єдину змішану оцінку.
- Ігнорування expansion-виручки, що занижує LTV для акаунтів, які зростають з часом.
- Застосування єдиного змішаного LTV до дуже різних сегментів клієнтів чи каналів залучення при прийнятті рішень щодо ціноутворення чи інвестицій у канали.

# Пов'язані метрики

- **CAC** — LTV стає дієвим лише в порівнянні з CAC через співвідношення LTV:CAC.
- **Churn Rate** — головний драйвер компонента "тривалості життя" в LTV.
- **ARPU** — вхідний параметр виручки на акаунт у формулі LTV.
- **Gross Margin** — перетворює ARPU на основі виручки в LTV на основі прибутку.
