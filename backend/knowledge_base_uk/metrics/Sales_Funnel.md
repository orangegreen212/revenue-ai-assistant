# Sales Funnel — Метрики конверсії SaaS

## Визначення

Sales Funnel (воронка продажів) — це поетапний шлях від впізнаваності до платного клієнта (і часто до expansion). У SaaS зазвичай включає маркетингові й продажні етапи: відвідувач → лід → MQL → SQL → opportunity → закрита угода, або product-led шлях: візит → реєстрація → активація → конверсія у платного клієнта. Аналітика воронки вимірює обсяги, коефіцієнти конверсії та швидкість переходу між етапами.

## Формула

Коефіцієнт конверсії етапу:

```
Конверсія (A → B) = Кількість, що дійшла до етапу B / Кількість, що увійшла на етап A
```

Загальна конверсія воронки:

```
Visitor-to-paid = Платні клієнти / Відвідувачі
```

Пропускна здатність воронки (приклад):

```
Очікувані перемоги = Opportunities × Win rate
Pipeline coverage = Вартість pipeline / Цільова виручка
```

Швидкість продажів (спрощено):

```
Velocity ≈ (# opportunities × win rate × середній розмір угоди) / тривалість циклу продажів
```

## Бізнес-інтерпретація

Воронка показує, де "витікає" зростання. Сильний верх воронки зі слабкою конверсією SQL-to-win вказує на проблеми продажів чи ICP; сильний win rate при малій кількості MQL вказує на проблему з генерацією попиту. Для PLG активація і час до цінності (time-to-value) часто важливіші за класичну кількість MQL. Аналізуй і **коефіцієнти**, і **абсолютні обсяги**, сегментуй воронку за каналом, сегментом та продуктом. Пов'язуй результати воронки з CAC, payback і новим MRR, щоб KPI маркетингу/продажів залишалися пов'язаними з виручкою.

## Типові помилки

- Порівняння коефіцієнтів конверсії між етапами з непослідовними визначеннями етапів у CRM.
- Оптимізація "марнославного" обсягу на вершині воронки, який ніколи не стає pipeline.
- Ігнорування часових лагів (MQL цього місяця стають виручкою наступного кварталу).
- Змішування self-serve та enterprise моделей продажів в одній воронці без окремих шляхів.
- Відстеження кількості етапів без win rate, тривалості циклу та середнього розміру угоди.

## Поради для співбесіди

**Q:** Як діагностувати падіння нового MRR за допомогою воронки продажів?

**A:** Побудуй міст від нового MRR назад через закриті угоди → opportunities → SQL → MQL → ліди, за каналом і сегментом. Перевір, чи впав обсяг, чи впали коефіцієнти конверсії, чи зменшився розмір угоди, чи розтягнувся цикл. Приклад: MQL стабільні, а win rate впав — можливо, проблема з ICP чи конкуренцією; win rate стабільний, а MQL впали — проблема генерації попиту. Кількісно оціни найбільший розрив і запропонуй один експеримент на кожен вузьке місце.

## Приклад SQL

```sql
-- Конверсія воронки за місяцем (етапи у стилі CRM)
WITH stages AS (
    SELECT
        DATE_TRUNC('month', created_at) AS month,
        COUNT(*) FILTER (WHERE stage_reached >= 'lead') AS leads,
        COUNT(*) FILTER (WHERE stage_reached >= 'mql') AS mqls,
        COUNT(*) FILTER (WHERE stage_reached >= 'sql') AS sqls,
        COUNT(*) FILTER (WHERE stage_reached >= 'opportunity') AS opportunities,
        COUNT(*) FILTER (WHERE stage_reached >= 'closed_won') AS wins
    FROM funnel_events
    GROUP BY 1
)
SELECT
    month,
    leads,
    mqls,
    sqls,
    opportunities,
    wins,
    mqls * 1.0 / NULLIF(leads, 0) AS lead_to_mql,
    sqls * 1.0 / NULLIF(mqls, 0) AS mql_to_sql,
    wins * 1.0 / NULLIF(opportunities, 0) AS opportunity_win_rate
FROM stages
ORDER BY month;
```
