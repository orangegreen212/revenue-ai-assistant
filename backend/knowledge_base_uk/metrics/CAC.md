# CAC — Вартість залучення клієнта (Customer Acquisition Cost)

## Визначення

Customer Acquisition Cost (CAC) — середня вартість залучення одного нового платного клієнта за період. Включає витрати на продажі й маркетинг (часто і пов'язані накладні витрати), поділені на кількість залучених нових клієнтів. CAC — ключовий показник юніт-економіки поруч з LTV та payback period.

## Формула

```
CAC = Витрати на продажі та маркетинг / Кількість нових залучених клієнтів
```

Повністю навантажений (fully loaded) варіант (рекомендований для серйозного аналізу):

```
CAC = (зарплати S&M + реклама + інструменти + агенції + комісії + пов'язані накладні витрати)
      / Нові платні клієнти
```

Blended vs paid:

```
Blended CAC = Загальні S&M / Усі нові клієнти
Paid CAC    = Витрати на платне залучення / Клієнти з платних каналів
```

## Бізнес-інтерпретація

CAC показує, наскільки дороге зростання. Зростання CAC може означати насичення каналу, конкурентний тиск чи неефективні витрати; падіння CAC — покращену конверсію, сильніший бренд чи product-led growth. Сам по собі CAC неповний — завжди порівнюй його з LTV (`LTV:CAC`) та з CAC payback у місяцях. Сегментуй CAC за каналом, сегментом і geo: blended CAC може приховувати, що enterprise прибутковий, а платна реклама для SMB — ні.

## Типові помилки

- Виключення зарплат продажів, комісій чи маркетингових інструментів з "повністю навантаженого" CAC.
- Ділення на трайли чи реєстрації замість платних клієнтів.
- Ігнорування затримки атрибуції (витрати в місяці N закриваються в місяці N+2).
- Використання blended CAC для рішень щодо каналів, які потребують розділення paid/organic.
- Порівняння CAC між компаніями з дуже різними моделями продажів (PLG vs enterprise-продажі).

## Поради для співбесіди

**Q:** Як порахувати CAC для SaaS-компанії з 3-місячним циклом продажів?

**A:** Краще використати когортний чи лаговий підхід: віднести витрати на продажі й маркетинг до періоду, коли були створені можливості (opportunities) (або застосувати послідовний лаг, наприклад, витрати в місяцях T−2..T відповідають закриттям у місяці T), потім поділити на нових платних клієнтів, що закрилися. Чітко вкажи вікно атрибуції. Також варто показати blended vs channel CAC і зазначити, чи витрати повністю навантажені.

## Приклад SQL

```sql
-- Місячний blended CAC (припускає, що фінанси експортують S&M витрати помісячно)
WITH new_customers AS (
    SELECT
        DATE_TRUNC('month', first_paid_date) AS cohort_month,
        COUNT(DISTINCT customer_id) AS new_customers
    FROM customers
    WHERE first_paid_date IS NOT NULL
    GROUP BY 1
),
sm_spend AS (
    SELECT
        DATE_TRUNC('month', spend_date) AS spend_month,
        SUM(amount) AS sm_cost
    FROM sales_marketing_costs
    GROUP BY 1
)
SELECT
    n.cohort_month,
    s.sm_cost,
    n.new_customers,
    s.sm_cost / NULLIF(n.new_customers, 0) AS cac
FROM new_customers n
JOIN sm_spend s ON n.cohort_month = s.spend_month
ORDER BY n.cohort_month;
```
