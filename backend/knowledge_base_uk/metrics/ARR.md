# ARR — Річний повторюваний дохід (Annual Recurring Revenue)

## Визначення

Annual Recurring Revenue (ARR) — це річна вартість повторюваної передплатної виручки. Це анаулізоване представлення прогнозованого доходу від підписок і головна top-line метрика, якою SaaS-компанії, інвестори та ради директорів вимірюють масштаб і зростання.

## Формула

```
ARR = MRR × 12
```

Безпосередньо з контрактів:

```
ARR = Σ (аналізована повторювана плата за кожну активну підписку)
```

Приклади нормалізації:

```
ARR місячного плану   = місячна плата × 12
ARR квартального плану = квартальна плата × 4
ARR багаторічної угоди = загальна вартість контракту / кількість років
```

ARR bridge (за період):

```
Ending ARR = Beginning ARR + New ARR + Expansion ARR − Contraction ARR − Churned ARR
```

## Бізнес-інтерпретація

ARR показує розмір і траєкторію повторюваної бази виручки. Ради директорів та інвестори використовують ARR для порівняння SaaS-компаній, бо він прибирає щомісячний шум і фокусується на контрактній повторюваній вартості. Зростання ARR разом зі здоровим Net New ARR вказує на масштабоване зростання; зростання ARR лише за рахунок знижок чи разових річних передплат може приховувати ризики утримання. Завжди аналізуй ARR разом з NRR, churn і CAC payback, щоб оцінити якість зростання.

## Типові помилки

- Врахування разових професійних послуг, впровадження чи обладнання як ARR.
- Врахування повної вартості багаторічного контракту як ARR у перший рік замість анаулізації.
- Змішування booked ARR, визнаної виручки та billings без чітких позначень.
- Врахування неповторюваних перевищень використання так, ніби це гарантована повторювана виручка.
- Звітування про зростання ARR без показу churned та contracted ARR у bridge.

## Поради для співбесіди

**Q:** У чому різниця між ARR і MRR, і коли використовувати кожен з них?

**A:** MRR — це щомісячний повторюваний run-rate; ARR — та сама повторювана база в річному вимірі (`ARR = MRR × 12`). Використовуй MRR для операційної щомісячної звітності, cohort bridges та коротких SaaS-циклів. Використовуй ARR для презентацій раді директорів, фандрейзингу, річного планування та enterprise-угод із річними контрактами. Завжди будь послідовним щодо того, що включено (лише повторюване) і як нормалізуються річні/багаторічні угоди.

## Приклад SQL

```sql
-- Зріз ARR з активних підписок (усі інтервали приведені до річного)
SELECT
    DATE_TRUNC('month', CURRENT_DATE) AS as_of_month,
    SUM(
        CASE billing_interval
            WHEN 'month' THEN amount * 12
            WHEN 'quarter' THEN amount * 4
            WHEN 'year' THEN amount
            ELSE NULL
        END
    ) AS total_arr
FROM subscriptions
WHERE status = 'active'
  AND (end_date IS NULL OR end_date > CURRENT_DATE);
```
