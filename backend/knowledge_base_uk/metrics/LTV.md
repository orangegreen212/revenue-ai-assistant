# LTV — Довічна цінність клієнта (Customer Lifetime Value)

## Визначення

Customer Lifetime Value (LTV, або CLV) оцінює загальний валовий прибуток (а іноді виручку), очікуваний від клієнта за весь час співпраці. У SaaS LTV зазвичай виводиться з ARPU, валової маржі та churn (або тривалості життя в місяцях). Використовується разом з CAC для оцінки економічної стійкості залучення клієнтів.

## Формула

Проста LTV на основі валової маржі (класичний SaaS-варіант):

```
LTV = ARPU × Валова маржа % / Customer Churn Rate
```

Через тривалість життя в місяцях:

```
Середня тривалість життя клієнта (місяців) = 1 / Місячний churn rate
LTV = ARPU × Валова маржа % × Середня тривалість життя
```

Варіант лише на основі виручки (менш бажаний для юніт-економіки):

```
LTV_revenue = ARPU / Churn Rate
```

Когортний LTV (точніший):

```
LTV = Σ (дисконтований очікуваний валовий прибуток за місяць для когорти)
```

## Бізнес-інтерпретація

LTV відповідає на питання, скільки цінності клієнт створює з часом. Здорові SaaS-компанії часто цілять **LTV:CAC ≥ 3:1**, з CAC payback менше ~12 місяців (залежно від контексту). Якщо LTV рахується на основі виручки, а не валового прибутку, співвідношення виглядають штучно сильними. Сегментуй LTV за планом і каналом залучення — високий blended LTV може приховувати, що один канал залучає клієнтів з низьким утриманням. Покращення LTV зазвичай приходить від нижчого churn, вищого ARPU/expansion або кращої валової маржі.

## Типові помилки

- Використання revenue LTV у співвідношенні LTV:CAC замість LTV на основі валового прибутку.
- Застосування річного churn у місячній формулі ARPU (одиниці мають збігатися).
- Припущення про постійний churn, коли ранні когорти йдуть значно швидше за пізніші.
- Ігнорування expansion (занижує LTV) або подвійний підрахунок.
- Використання єдиного blended LTV для рішень щодо ціноутворення та каналів у різних сегментах.

## Поради для співбесіди

**Q:** Як порахувати LTV, і яке співвідношення LTV:CAC вважається здоровим?

**A:** Поширена формула — `LTV = ARPU × Валова маржа % / Churn`. Узгодь періоди (місячний ARPU з місячним churn). Для порівняння з CAC краще використовувати LTV на основі валового прибутку. Емпіричне правило — LTV:CAC близько 3:1 або вище, але також перевіряй payback period і обмеження по капіталу. Згадай когортний LTV як точніший підхід, коли churn і expansion змінюються з часом.

## Приклад SQL

```sql
-- Приблизний LTV за планом через місячний ARPU, маржу та місячний logo churn
WITH plan_arpu AS (
    SELECT
        plan_name,
        AVG(mrr) AS arpu
    FROM subscriptions
    WHERE status = 'active'
    GROUP BY plan_name
),
plan_churn AS (
    SELECT
        plan_name,
        COUNT(*) FILTER (WHERE churned_in_month) * 1.0
            / NULLIF(COUNT(*) FILTER (WHERE active_at_month_start), 0) AS monthly_churn
    FROM subscription_month_facts
    GROUP BY plan_name
)
SELECT
    a.plan_name,
    a.arpu,
    c.monthly_churn,
    (a.arpu * 0.80) / NULLIF(c.monthly_churn, 0) AS ltv_gross_profit_80pct_margin
FROM plan_arpu a
JOIN plan_churn c ON a.plan_name = c.plan_name;
```
