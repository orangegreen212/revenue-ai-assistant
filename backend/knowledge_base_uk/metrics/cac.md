# Визначення

Customer Acquisition Cost (CAC) — це середня вартість залучення одного нового платного клієнта за період, розрахована як загальні витрати на продажі й маркетинг, поділені на кількість нових клієнтів, залучених за цей період.

# Чому це важливо

Сам по собі CAC мало про що говорить — $500 CAC може бути чудовим або жахливим залежно від того, скільки цей клієнт коштуватиме за весь час співпраці (LTV) і як швидко повертаються витрати (payback period). CAC стає значущим лише в парі з цими двома супутніми метриками.

# Формула

```
CAC = Витрати на продажі й маркетинг / Залучені нові клієнти
```

**Повністю навантажений (fully-loaded) CAC** (рекомендований для серйозного аналізу юніт-економіки) включає всі пов'язані витрати:

```
CAC = (зарплати S&M + реклама + інструменти + агенції
       + комісії + пов'язані накладні витрати) / Нові платні клієнти
```

**Blended vs. paid CAC:**

```
Blended CAC = Загальні витрати S&M / Усі нові клієнти
Paid CAC    = Витрати на платне залучення / Клієнти лише з платних каналів
```

# Приклад

Компанія витрачає $50 000 на продажі й маркетинг за місяць і залучає 100 нових платних клієнтів.

```
CAC = $50 000 / 100 = $500 на клієнта
```

# Типові помилки

- Виключення зарплат продажів, комісій чи вартості маркетингових інструментів з "повністю навантаженого" CAC.
- Ділення на тріали чи реєстрації в безкоштовному тарифі замість платних клієнтів.
- Ігнорування лагу між витратами й результатом (гроші, витрачені в місяці N, часто конвертуються в клієнтів у місяці N+1 чи пізніше), що спотворює помісячний CAC без коригування.
- Використання єдиного blended CAC для рішень на рівні каналів, коли платні й органічні канали мають дуже різну вартість.
- Порівняння CAC між компаніями з принципово різними моделями продажів (self-serve/PLG vs. enterprise-продажі), ніби вони еквівалентні.

# Пов'язані метрики

- **LTV** — довічна цінність клієнта; CAC значущий лише в контексті співвідношення LTV:CAC.
- **CAC Payback** — час (у місяцях), потрібний для повернення CAC з валового прибутку; більш дієва супутня метрика, ніж сам CAC.
- **ARPU** — входить і в LTV, і в розрахунок payback поруч із CAC.
