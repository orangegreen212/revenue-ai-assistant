# Визначення

Gross Revenue Retention (GRR), або Gross Dollar Retention (GDR), вимірює, скільки повторюваного доходу від початкової когорти утримано після churn і contraction — **без урахування expansion**. Це ізолює якість утримання саму по собі, без апсейлів, які маскують реальний churn.

# Чому це важливо

GRR відповідає на вужче, суворіше питання, ніж NRR: "Чи утримуємо ми дохід, який уже мали?" Оскільки expansion виключений, GRR ніколи не може перевищити 100%. Це робить його чистішим діагностичним інструментом для проблем churn і даунгрейдів — компанія може мати сильний NRR через кілька великих expansion, тоді як GRR покаже, що churn у ширшій базі — реальна проблема.

# Формула

```
GRR = (Beginning ARR − Contraction − Churn) / Beginning ARR
```

Зв'язок з NRR:

```
NRR = GRR + (Expansion / Beginning ARR)
```

GRR математично обмежений 100% — GRR понад 100% означає, що expansion помилково потрапив у розрахунок.

# Приклад

Та сама когорта, що й у прикладі NRR: $1 000 000 початковий ARR, $40 000 contraction, $60 000 churn (expansion тут виключений).

```
GRR = ($1 000 000 − $40 000 − $60 000) / $1 000 000
GRR = $900 000 / $1 000 000 = 90%
```

# Типові помилки

- Випадкове включення expansion-виручки, через що GRR може здаватися вищим за 100% — значення, яке для цієї метрики математично неможливе.
- Використання різних когортних вікон для GRR і NRR (наприклад, місячний GRR vs. річний NRR) з подальшим прямим порівнянням.
- Трактування високого змішаного GRR як достатнього доказу здоров'я без перевірки, чи не тримає один великий сегмент (наприклад, enterprise) на собі значно слабший сегмент SMB.
- Плутанина GRR (на основі виручки) з утриманням логотипів/клієнтів (на основі кількості) — компанія може утримувати більшість виручки, втрачаючи багато дрібних акаунтів.

# Пов'язані метрики

- **NRR** — додає expansion назад; `NRR = GRR + (Expansion / Beginning ARR)`.
- **Churn Rate** — GRR по суті дорівнює 100% мінус revenue-churn і contraction разом.
- **Customer Segmentation** — GRR варто розбивати за тарифом, сегментом та віком когорти, щоб знайти, де концентруються проблеми утримання.
